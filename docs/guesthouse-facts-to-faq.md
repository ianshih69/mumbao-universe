# guesthouse-rules.md 正式事實搬移清單

產出日期：2026-07-23

本文件只整理「需要人工搬進 FAQ 主檔」的正式事實，不自動修改 `faq-master.csv` 或 `faq-items.json`。

## 搬移原則

- `guesthouse-rules.md` 可保留共同角色、語氣與總則。
- 會被問慢寶正式回答的時間、價格、費用、禁止事項、設備與承諾，應整理進 `faq-master.csv`。
- 人工確認後再決定 `status=approved`；未確認前建議先用 `needs_review`。
- 金額、退款、押金、訪客、早餐價格等高風險題，優先使用 `collect_info` 或 `ask_human`。

## 建議處理順序

1. 先處理時間與金額：入住、退房、早餐、訪客費、押金。
2. 再處理禁止事項：禁菸、明火、煙火、砸蛋糕、砸水球。
3. 接著處理設施清單，將確定有的設備拆成可直接回答的 FAQ。
4. 最後整理寵物細節題，將不可承諾的費用、數量、大型犬改為 `collect_info` 或 `ask_human`。
